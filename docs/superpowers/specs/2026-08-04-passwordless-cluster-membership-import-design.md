# 无密码集群成员标注导入设计

## 背景

现有 Excel 设备导入要求每行填写密码，并把所有 `Device` 记录视为可采集设备。部分集群资产只需要登记名称、地址和集群归属，用于集群模式展示，不具备或不允许提供远程登录密码。若简单保存空密码，集群策略、定时任务、手动扫描或批量扫描仍可能触发连接并持续产生认证失败。

## 目标

- Excel 密码为空且所属集群非空时，允许创建“仅标注设备”。
- 仅标注设备计入集群成员数量，并出现在集群拓扑成员列表中。
- 仅标注设备不执行导入连接测试，不进入首次、定时、手动或批量扫描。
- 有密码设备保持现有导入、加密、连接测试和首次扫描流程。
- 无密码行命中现有设备时，该行报错并跳过，不修改现有设备或集群归属，同时写入服务器应用日志。
- 为仅标注设备补充并验证密码后，可转换为正常采集设备。

## 数据模型与迁移

`devices` 增加非空布尔字段：

```text
collection_enabled BOOLEAN NOT NULL DEFAULT 1
```

- 现有设备迁移后默认 `true`，行为不变。
- 正常创建或有密码导入的设备为 `true`。
- 无密码导入的仅标注设备为 `false`。
- 仅标注设备的 `encrypted_password` 保存现有加密组件生成的空字符串密文，避免把密码列改为可空并扩大凭据处理分支。

数据库模式版本递增至 9。迁移使用幂等列检查，旧数据库启动时自动增加字段，不修改现有设备状态。

## Excel 规则

模板列和表头保持不变，避免破坏已有文件。填写说明调整为：

- 密码有值：按正常可采集设备导入。
- 密码为空：必须填写所属集群，创建仅标注设备。
- 密码为空且所属集群为空：该行校验失败。
- 设备名称、主机地址、操作系统、端口和用户名仍按现有规则填写；它们共同提供页面展示、地址归属及设备唯一性判断。

模板示例仍使用有密码设备，不在工作簿中写入真实凭据。

## 重复设备

重复身份继续按主机地址、端口和用户名判断。

- 有密码重复行保持现有“已跳过”行为。
- 无密码重复行按用户要求记为导入错误，不更新现有设备集群归属。
- 行结果信息为“设备已存在，未修改集群归属”。
- 服务器应用日志以警告级别记录批次 ID、Excel 行号、设备名称、主机地址、端口、用户名和冲突原因，不记录密码或加密密文。

## 导入批次状态

有密码设备：

- `import_status = imported`；
- `test_status = pending`；
- 增加导入批次待测试数量；
- 测试成功后进入现有首次扫描批次。

无密码仅标注设备：

- `import_status = imported`；
- 导入说明为“仅标注集群设备，不执行连接测试”；
- `test_status = not_applicable`；
- 不增加待测试数量，也不进入首次扫描批次。

混合批次只测试有密码设备。批次中仅包含无密码设备时，导入完成后直接进入 `completed`，不会停留在测试中。

## 扫描防线

`collection_enabled` 是独立于 `scheduled_enabled` 的强制采集门禁。集群扫描策略仍可统一更新采集周期与定时开关，但不能使仅标注设备变为可采集。

- 调度器只注册 `collection_enabled = true` 且 `scheduled_enabled = true` 的设备。
- 调度器同步仅标注设备时移除已有任务并返回。
- 全部设备和集群批量扫描在查询设备 ID 时排除仅标注设备。
- 扫描队列在直接接收设备 ID 时再次排除仅标注设备，防止内部调用绕过 API。
- 手动扫描仅标注设备返回 HTTP 409，提示“该设备仅用于集群标注，未配置采集凭据”。
- `ScanService.run()` 在执行采集前进行最终防御检查，避免遗留任务或竞态触发远程连接。

## 转换为可采集设备

现有设备更新 API 在仅标注设备提交非空密码时：

1. 使用当前或同时提交的地址、端口、用户名和操作系统执行连接测试；
2. 测试成功后加密保存密码；
3. 将 `collection_enabled` 设置为 `true`；
4. 按当前集群策略同步调度器。

连接测试失败时不保存密码、不改变标注状态。单纯修改名称、集群或保留策略不会启用采集。API 不允许客户端直接把 `collection_enabled` 从 `false` 改为 `true`，状态转换必须由成功的密码验证驱动。

## API 与界面

`DeviceRead` 增加 `collection_enabled`，不在创建或更新请求模型中暴露可直接赋值的同名字段。

设备列表中：

- 仅标注设备显示“仅标注”标识；
- 状态点保持未采集状态；
- “立即采集”按钮禁用并提供未配置凭据提示；
- 集群名称、设备名称和地址继续正常显示。

集群模式继续使用所有 `Device` 记录构造成员列表，因此仅标注设备即使没有扫描快照，也会显示在对应集群中。连接边仍只来自具备成功扫描的数据，不为仅标注设备生成虚假连接。

## 日志与安全

- 无密码重复行记录结构化应用日志，包含定位该行所需的非敏感设备字段。
- 日志、导入行结果和下载报告都不包含密码或密文。
- 空密码仅以加密后的值保存在数据库，不保存明文空值标记以外的凭据信息。
- 现有日志脱敏过滤继续生效。

## 测试

- 模板说明密码为条件必填，并说明无密码必须填写集群。
- 无密码且有集群时创建 `collection_enabled = false` 的设备，测试状态为不适用。
- 无密码且无集群时行校验失败。
- 无密码重复设备时行状态为错误、现有集群不变，并记录不含密码的日志。
- 有密码重复设备保持跳过行为。
- 混合批次只测试有密码设备。
- 纯标注批次直接完成且不创建首次扫描任务。
- 调度器、手动扫描、全部扫描、集群扫描和队列防御均排除仅标注设备。
- 为仅标注设备提交有效密码后启用采集；测试失败时保持禁用。
- 设备 API 与列表展示“仅标注”状态。
- 集群拓扑包含无扫描快照的仅标注成员，并保持边数据不变。
- 旧数据库迁移后现有设备全部保持可采集。

## 非目标

- 不允许缺少设备名称、主机地址、操作系统、端口身份或用户名的资产行。
- 不通过无密码导入修改已存在设备的集群归属。
- 不为仅标注设备伪造扫描快照或连接边。
- 不新增独立集群资产表。
- 不改变密码加密算法或密钥管理方式。
