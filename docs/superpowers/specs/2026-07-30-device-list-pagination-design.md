# 设备管理列表搜索、分页与跳转——设计说明

## 1. 背景与目标

当前 `/devices` 页面一次查询并渲染全部设备。“已接入设备”达到数百或数千台时，
页面需要长距离滚动，也无法快速定位指定设备。

本次改造目标：

- 设备列表改为数据库级分页，避免一次加载全部设备。
- 支持按设备名称或主机地址/IP搜索全部设备。
- 支持上一页、下一页、页码按钮和输入页码直接跳转。
- 支持每页显示 20、50、100 台设备，默认 20 台。
- 搜索和分页状态写入 URL，刷新、复制链接和浏览器返回后仍可恢复。
- 保持设备新增、测试连接、扫描、查看拓扑、删除、Excel 导入和集群扫描功能不变。

## 2. 范围

### 2.1 包含

- `/devices` 页面查询参数和服务端分页。
- 设备名称和主机地址/IP的包含搜索。
- 当前页设备及其所属集群的批量加载。
- 设备列表工具栏、结果计数和分页控件。
- 页码窗口与省略号生成逻辑。
- 直接输入页码跳转。
- 搜索、分页、页容量的 URL 状态保持。
- 桌面端和窄屏布局。
- 服务、页面和浏览器验收测试。

### 2.2 不包含

- 不修改 `/api/devices` 的现有返回结构或用途。
- 不搜索用户名、集群名称、操作系统或扫描状态。
- 不增加模糊拼写纠正、搜索建议或全文搜索引擎。
- 不增加设备排序切换。
- 不增加批量勾选或批量删除。
- 不修改拓扑页和其他页面的设备下拉框。

## 3. 已确认的交互规则

### 3.1 搜索字段

搜索词仅匹配：

- `Device.name`
- `Device.host`

匹配方式为包含搜索。搜索只在以下操作时执行：

- 点击“搜索”按钮；
- 搜索框内按回车。

不做输入自动搜索。

### 3.2 分页

- 默认每页 20 台。
- 用户可切换为 20、50、100 台。
- 切换每页数量后返回第 1 页。
- 提供上一页、下一页、页码按钮。
- 始终显示首页、末页和当前页附近页码。
- 页数很多时使用省略号压缩。
- 提供页码输入框和“跳转”按钮。
- 当前页按钮显示选中状态并禁止重复点击。

### 3.3 URL 状态

页面使用以下查询参数：

```text
/devices?q=10.0.0.1&page=3&page_size=20
```

- `q`：清理首尾空格后的搜索词，默认为空。
- `page`：从 1 开始，默认 1。
- `page_size`：仅允许 20、50、100，默认 20。

所有分页链接保留 `q` 和 `page_size`。搜索和每页数量变化时将 `page` 重置为 1。

## 4. 架构与组件

### 4.1 设备列表服务

新增 `app/services/device_listing.py`，集中处理设备列表查询，避免页面路由承担
SQL、页码计算和分页窗口生成等多种职责。

服务提供：

```python
@dataclass(frozen=True)
class DevicePage:
    items: list[Device]
    query: str
    page: int
    page_size: int
    total_items: int
    total_pages: int
    first_item: int
    last_item: int
    page_links: list[int | None]


def list_device_page(
    session: Session,
    query: str,
    page: int,
    page_size: int,
) -> DevicePage:
    ...
```

其中 `None` 表示分页控件中的省略号。

### 4.2 页面路由

`devices_page` 接收 `q`、`page`、`page_size`，调用 `list_device_page`，并将以下内容
传给模板：

- 当前页设备；
- 搜索词；
- 当前页和每页数量；
- 匹配总数和总页数；
- 当前显示范围；
- 压缩后的页码列表；
- 全部集群，供设备表单和集群扫描下拉框继续使用。

现有模板变量 `devices` 继续表示表格当前页设备，减少对已有模板和脚本的改动。
设备总数徽标改用 `device_page.total_items`。

### 4.3 模板和脚本

`app/templates/devices.html` 在“已接入设备”模块中增加：

- GET 搜索表单；
- 搜索输入框；
- 搜索按钮；
- 有搜索词时显示的清除链接；
- 每页数量选择器；
- 匹配总数和当前显示范围；
- 页码、上一页、下一页；
- 页码输入框和跳转按钮。

新增少量页面脚本：

- 每页数量变化时修改 URL，并返回第 1 页；
- 页码跳转时将输入限制在 `1..total_pages`；
- 回车和点击“跳转”使用相同行为。

现有扫描和删除按钮继续只绑定当前页渲染出的设备。

## 5. 数据查询

### 5.1 搜索条件

搜索词清理首尾空格后，对设备名称和主机地址执行 OR 包含匹配。

SQLAlchemy 查询使用参数绑定和自动转义：

```python
or_(
    Device.name.contains(query, autoescape=True),
    Device.host.contains(query, autoescape=True),
)
```

因此 `%` 和 `_` 按普通字符搜索，不作为用户控制的通配符。

### 5.2 统计和取页

查询分两步执行：

1. 使用相同过滤条件统计匹配总数。
2. 按 `Device.name`、`Device.id` 稳定排序，通过 `offset` 和 `limit` 读取当前页。

当前页查询使用 `selectinload(Device.cluster)`，避免模板逐行读取集群时触发额外查询。

### 5.3 页码修正

- 无匹配结果时：`total_pages = 0`，内部展示页仍为 1，不生成分页按钮。
- 有结果时：将请求页码限制在 `1..total_pages`。
- 请求页码超过总页数时，重定向到最后一个有效页，并保留 `q` 和
  `page_size`，使浏览器 URL 与实际页码一致。
- 删除当前页最后一台设备并刷新后，会自然回到上一有效页。

## 6. 页面状态和文案

未搜索且无设备：

```text
尚未接入设备
```

搜索无结果：

```text
未找到匹配的设备
```

有结果时：

```text
共 386 台设备，当前显示 21–40
```

搜索框占位文字：

```text
搜索设备名称或主机地址
```

所有新增可见文案使用中文；SSH、WinRM、IP等专业术语保持不变。

## 7. 响应式与可访问性

- 搜索工具栏在宽屏横向排列，在窄屏自动换行。
- 分页控件允许换行，不产生页面横向溢出。
- 搜索框具有可访问标签。
- 当前页使用 `aria-current="page"`。
- 禁用状态使用原生 `disabled` 属性。
- 页码输入设置最小值 1 和动态最大值。
- 所有按钮可通过键盘访问。

## 8. 异常与边界处理

- `q` 最大长度为 255；超过限制返回参数校验错误。
- `page < 1` 返回参数校验错误。
- `page_size` 不是 20、50、100 时返回参数校验错误。
- 空白搜索词按未搜索处理。
- 特殊字符通过 SQL 参数绑定和 Jinja 转义处理。
- 页码输入为空或不是数字时不跳转，并显示中文提示。
- 页码输入超过范围时自动限制到最近有效页。
- 数据库错误沿用现有应用异常处理，不在浏览器中暴露 SQL 内容。

## 9. 测试方案

### 9.1 服务测试

- 45 台设备在 20 台每页时分为 20、20、5。
- 设备名称搜索可命中跨页设备。
- 主机地址搜索可命中跨页设备。
- 用户名和集群名称不会被搜索命中。
- `%`、`_` 按普通字符处理。
- 20、50、100 三种页容量计算正确。
- 超范围页码修正到最后一页。
- 无结果时页数、范围和页码列表正确。
- 大量页码时正确生成首页、末页、当前页邻近项和省略号。

### 9.2 页面测试

- `/devices` 默认只渲染前 20 台。
- 总数徽标显示全部匹配设备数，而不是当前页数量。
- 搜索表单和分页控件使用正确中文文案。
- 分页链接保留 `q` 和 `page_size`。
- 清除搜索链接返回无搜索条件的第 1 页。
- 搜索无结果时显示正确空状态。
- 设备表单、Excel 导入和集群扫描控件仍存在。

### 9.3 前端脚本测试

- 每页数量变化保留搜索词并重置页码。
- 页码跳转限制在有效范围。
- 跳转按钮和回车触发相同逻辑。

### 9.4 浏览器验收

使用临时批量设备数据验证：

- 搜索按钮和搜索框回车可执行搜索；
- 搜索可从全部设备中命中名称或主机地址；
- 上一页、下一页和页码按钮正确；
- 输入页码可直接跳转；
- 切换 20、50、100 正确；
- URL 始终反映当前状态；
- 删除当前页最后一项后回到有效页；
- 窄屏无横向溢出；

验收后删除全部临时数据，不影响用户已有设备。
