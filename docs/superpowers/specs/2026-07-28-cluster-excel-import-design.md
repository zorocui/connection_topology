# 集群管理、Excel 批量导入与集群拓扑设计

## 1. 目标

在现有服务器连接拓扑系统上增加：

1. 设备所属集群管理。
2. Excel 批量导入设备。
3. 导入后后台逐台验证 SSH/WinRM 连接。
4. 集群模式拓扑：同一集群内设备连接不显示，只显示跨集群、未分组设备和外部地址之间的连接。

现有单设备添加、设备模式拓扑、采集历史和凭据加密行为保持兼容。

## 2. 已确认的产品规则

- 集群既可从已有列表选择，也可在添加设备时快速创建。
- Excel 正确行导入，错误行记录原因，不回滚其他正确行。
- Excel 包含明文密码列；密码读取后立即加密保存。
- 重复设备跳过并写入结果报告。
- 导入完成后由后台最多并行 3 台设备执行连接测试。
- 设备地址使用精确值及主机名解析所得 IP 匹配受管设备。
- 集群模式下，未分组设备按单独设备节点显示。
- 拓扑页采用顶部“设备模式 / 集群模式”切换。

## 3. 数据模型

### 3.1 Cluster

- `id`
- `name`：去除首尾空格后唯一，长度 1 至 100
- `description`：可空，最大 500 字符
- `created_at`
- `updated_at`

删除集群时，相关设备的 `cluster_id` 设为空，不删除设备、凭据、采集批次或连接记录。

### 3.2 Device 扩展

新增：

- `cluster_id`：可空，关联 `Cluster`

设备创建和更新接口同时支持：

- `cluster_id`：选择已有集群
- `new_cluster_name`：快速创建新集群

两者不能同时提供。快速创建时先按规范化名称查找，存在则复用，不存在则创建。

### 3.3 ImportBatch

- `id`
- `filename`
- `status`：`importing`、`testing`、`completed` 或 `failed`
- `total_rows`
- `imported_rows`
- `skipped_rows`
- `error_rows`
- `test_pending_rows`
- `test_success_rows`
- `test_failed_rows`
- `created_at`
- `finished_at`
- `fatal_error`

### 3.4 ImportRowResult

- `id`
- `batch_id`
- `row_number`
- `device_name`
- `host`
- `device_id`：可空
- `import_status`：`imported`、`skipped` 或 `error`
- `import_message`
- `test_status`：`pending`、`success`、`failed` 或 `not_applicable`
- `test_message`

导入结果不保存密码、密码密文或原始整行内容。

## 4. 数据库升级

现有系统仅使用 SQLAlchemy `create_all`，无法自动为已有表增加列。本功能增加轻量版本化迁移器：

1. 创建 `schema_versions` 表。
2. 创建 `clusters`、`import_batches` 和 `import_row_results` 表。
3. 为已有 `devices` 表增加可空 `cluster_id` 外键列。
4. 创建集群名称唯一索引和设备集群索引。
5. 记录迁移版本。

迁移在应用启动、调度器启动之前执行，并放在数据库事务中。已有设备默认未分组，历史数据和加密凭据不变化。删除集群时由服务层先将设备设为未分组，保证 SQLite 环境下行为一致。

## 5. 集群管理

提供接口：

- `GET /api/clusters`
- `POST /api/clusters`
- `PUT /api/clusters/{id}`
- `DELETE /api/clusters/{id}`

设备管理页面增加：

- 所属集群下拉框
- “快速新建集群”输入项
- 集群清单与成员数量
- 集群重命名
- 删除集群二次确认

集群名称比较时去除首尾空格并使用大小写不敏感匹配。重名返回 409。

## 6. Excel 模板

下载接口：

- `GET /api/imports/template`

文件名为 `设备批量导入模板.xlsx`，工作表名为 `设备导入`。首行字段固定为：

1. 设备名称
2. 主机地址
3. 操作系统
4. 端口
5. 用户名
6. 密码
7. 所属集群
8. 采集间隔（分钟）
9. 启用定时采集

模板包含一行不含真实凭据的示例和字段说明工作表。操作系统仅允许 `linux` 或 `windows`；启用定时采集仅允许 `是` 或 `否`。

## 7. Excel 导入

上传接口：

- `POST /api/imports`

限制：

- 只接受 `.xlsx`
- 最大 5 MB
- 最多 1000 条数据
- 必须使用固定表头
- 空白行不计入数据行
- 不保存上传原文件
- 使用 `openpyxl` 的普通工作簿模式读取，不执行宏或公式

逐行处理：

1. 读取并规范化字段。
2. 校验设备名称、主机地址、系统类型、端口、用户名、密码、采集间隔和定时标记。
3. 端口为空时，Linux 使用 22，Windows 使用 5985。
4. 采集间隔为空时使用 5 分钟。
5. 按“主机地址 + 端口 + 用户名”查重；重复行记为 `skipped`。
6. 所属集群非空时按名称查找或创建。
7. 使用 Fernet 加密密码。
8. 每行使用独立事务保存设备和结果。
9. 错误行只保存脱敏原因。

完成导入阶段后，批次状态从 `importing` 进入 `testing`。接口返回批次编号和统计数据，页面轮询批次详情。

## 8. 后台连接验证

成功导入的设备进入后台验证队列，最多并行 3 台。验证复用现有 Linux/Windows 采集器的 `test_connection`。

为避免应用重启造成任务丢失：

- `pending` 记录持久化在 `ImportRowResult`。
- 应用启动时重新调度仍为 `pending` 的记录。
- 单个设备测试完成后立即更新行结果和批次统计。
- 全部待测试行结束后，将批次更新为 `completed`。

测试失败不会删除设备。密码错误、超时、服务不可用和命令不可用分别显示现有中文错误。

批次详情接口：

- `GET /api/imports/{batch_id}`
- `GET /api/imports/{batch_id}/rows`
- `GET /api/imports/{batch_id}/report`

报告接口生成不含密码的 `.xlsx`，字段为行号、设备名称、主机地址、导入状态、导入说明、连接测试状态和连接测试说明。

## 9. 对端设备识别

集群拓扑需要把连接的对端 IP 映射为受管设备。

地址索引包含：

- 设备 `host` 本身；若为 IP 则规范化后直接索引。
- `host` 为主机名时，通过系统 DNS 解析的 IPv4/IPv6 地址。

DNS 结果缓存 10 分钟。解析失败不阻止拓扑生成，只是不为该主机名增加解析地址。多个设备解析到同一地址时，该地址视为不唯一，不自动归属任何设备，并在拓扑响应中返回警告。

## 10. 集群拓扑聚合

新增接口：

- `GET /api/topology/clusters`

数据来源为每台设备最近一次成功采集快照。设备没有成功快照时仍作为集群成员或未分组节点返回，但不产生连接边。

节点规则：

- 有集群的来源设备聚合为集群节点。
- 未分组来源设备保留为设备节点。
- 对端可匹配受管设备时，目标聚合为其集群或设备节点。
- 对端无法匹配受管设备时，按对端 IP 聚合为外部节点。

边规则：

- 来源设备和目标设备属于同一非空集群时忽略。
- 来源节点和目标节点相同时忽略。
- 跨集群连接聚合为有方向的“集群 → 集群”边。
- 集群与未分组设备、未分组设备之间、受管节点与外部 IP 之间均保留。
- 无对端的 TCP/UDP 监听记录不进入集群拓扑。
- 相同来源节点和目标节点的连接合并，边显示连接总数。

每条聚合边保留构成它的连接明细：

- 来源设备
- 目标设备或外部 IP
- 协议
- 本地/对端地址和端口
- 状态
- PID
- 进程名
- 快照编号和时间

## 11. 集群拓扑页面

拓扑页顶部增加分段切换：

- 设备模式
- 集群模式

设备模式保持现有逻辑。集群模式隐藏单设备选择器，显示：

- 集群筛选
- 协议筛选
- 状态筛选
- 进程筛选
- 快照时间说明

点击集群节点时，右侧显示：

- 集群名称
- 成员设备及地址
- 每台设备最近采集状态和快照时间
- 聚合外部连接数

点击聚合边时，右侧显示构成该边的来源设备、目标设备或 IP 及连接明细。

页面明确提示：集群拓扑使用各设备最近一次成功快照，数据并非严格同一时刻产生。

## 12. 页面导入流程

设备管理页增加“批量导入”入口：

1. 下载模板。
2. 选择 `.xlsx` 文件。
3. 上传前显示明文密码安全提示。
4. 上传后显示导入、跳过和错误统计。
5. 后台测试期间自动更新待测试、成功和失败数量。
6. 可展开逐行结果。
7. 可下载不含密码的结果报告。

## 13. 异常处理

以下情况拒绝整个文件并创建失败批次或直接返回 422：

- 文件扩展名错误
- 文件超过 5 MB
- 工作簿损坏
- 缺少 `设备导入` 工作表
- 表头不匹配
- 数据行超过 1000

以下情况仅使当前行失败：

- 必填字段为空
- 系统类型、端口、采集间隔或定时标记无效
- 密码为空
- 集群名称过长
- 数据库写入冲突

错误文本不得包含密码、密码密文或原始异常中的认证数据。

## 14. 测试

### 14.1 数据库

- 空数据库直接创建最新结构。
- 现有数据库增加集群字段且数据不丢失。
- 删除集群后设备变为未分组。

### 14.2 Excel

- 模板字段、示例和说明正确。
- 正确行、错误行、空白行和重复行混合导入。
- 默认端口和采集间隔。
- 自动创建与复用集群。
- 密码只以密文保存。
- 文件、日志和结果报告不泄露密码。
- 文件类型、大小、表头和行数限制。

### 14.3 后台验证

- 最多并行 3 台。
- 成功和失败分别统计。
- 应用重启后恢复待测试行。
- 测试失败不删除设备。

### 14.4 集群拓扑

- 同集群设备连接隐藏。
- 跨集群连接聚合。
- 未分组设备保持独立。
- 外部 IP 保留。
- 主机名解析地址可匹配设备。
- 地址冲突时不错误归属。
- 没有成功快照的设备仍显示。
- 设备模式现有行为不回归。

## 15. 验收标准

1. 可创建、选择、重命名和删除集群。
2. 添加或编辑设备时可选择已有集群或快速创建集群。
3. 可下载模板并批量导入最多 1000 台设备。
4. 正确、跳过和错误行按规则分别处理。
5. 导入密码加密保存，结果和日志不泄露密码。
6. 导入后后台逐台测试连接，并可查看持久化结果。
7. 拓扑可切换设备模式和集群模式。
8. 集群内部连接不显示。
9. 跨集群、未分组设备和外部连接正确聚合。
10. 现有数据库、设备模式和采集功能通过回归测试。
