# 密集拓扑可读性改造设计

## 背景

当前拓扑使用 Cytoscape `concentric` 布局。普通节点尺寸为 `38px`，节点间最小
间距为 `90px`，布局边距为 `76px`，绘制完成后还会强制执行全图适配。当对端
较多时，这些参数会产生较长连线；全图适配又会进一步缩小节点和标签，导致短线、
端点及连接数量难以辨认。

## 目标

- 保留所有对端 IP，不通过默认聚合隐藏节点。
- 使用紧凑多圈布局缩短平均连线长度。
- 保持节点、标签和连接数量在密集拓扑下仍可辨认和点击。
- 支持点击节点或连线后聚焦相关关系。
- 同时改善设备模式和集群模式。
- 保留现有筛选、详情面板、缩放和拖动画布能力。

## 非目标

- 不修改后端拓扑接口、数据库或采集行为。
- 不按网段、协议或业务类型合并外部节点。
- 不引入新的前端框架或 Cytoscape 扩展。
- 不改变设备模式与集群模式的数据含义。

## 选定方案

采用“紧凑多圈 + 大节点 + 焦点高亮”。未选择分组聚合，因为用户需要直接看到
全部对端 IP；未选择把所有节点压入单圈，因为节点会随数量增长而变得过小。

## 布局设计

### 圈层分配

绘制前为节点计算仅供前端布局使用的 `layoutLevel`：

- 设备模式：服务器位于中心最高层级；对端节点按稳定顺序分批放入由内向外的
  多个圈层。
- 集群模式：集群节点和受管设备处于中心或内圈；外部地址按稳定顺序分批放入
  后续圈层。
- 同类节点按节点 ID 排序，确保重复绘制时位置顺序稳定。
- 第一圈容纳 8 个节点，第二圈容纳 12 个节点，之后每增加一圈容量增加 4 个。
- 集群模式先按上述容量放置全部集群节点和受管设备，再从下一圈开始放置外部
  地址，保证两类节点不会混在同一圈层。
- 筛选后的节点集合重新计算圈层，避免保留空缺位置。

仍使用项目已内置的 Cytoscape `concentric` 布局，通过 `layoutLevel` 控制圈层，
不增加第三方依赖。布局动画保留，但缩短不必要的边距和节点间距。

### 尺寸与间距

- 普通对端和外部节点为 `52px × 52px`。
- 服务器节点为 `82px × 56px`。
- 集群节点为 `94px × 64px`。
- 节点标签字号由 `10px` 提升至 `12px`。
- 连接数量标签字号由 `9px` 提升至 `11px`，增加背景内边距。
- 连接最小宽度由 `1px` 提升至 `2px`，连接数增加时最高映射到 `8px`。
- 布局边距从 `76px` 降低至 `36px`，`minNodeSpacing` 从 `90px` 降低至
  `44px`。

### 初始视图

绘制完成后先计算全图适配比例：

- 如果全图适配后的缩放比例不低于 `0.7`，则完整显示全部拓扑。
- 如果适配比例低于 `0.7`，则使用 `0.7` 并将服务器或节点 ID 最小的受管节点居中；
  超出画布的节点通过拖动和滚轮缩放查看。
- Cytoscape 最小缩放保持 `0.4`，便于用户主动查看全局；最大缩放提高至 `2.5`。
- 不再为了单屏显示全部节点而无限缩小节点。

## 焦点交互

### 点击节点

选中节点、其直接相连的边以及相邻节点保持正常亮度；相关边加粗并使用强调色。
其余节点和边降低透明度。右侧详情面板继续显示该节点关联的连接。

### 点击连线

选中连线及两端节点保持正常亮度，连线加粗并高亮；其他元素淡化。右侧详情面板
继续显示该连线聚合的连接明细。

### 清除焦点

- 点击画布空白处清除焦点。
- 筛选条件变化并重新绘图时清除旧焦点。
- “重置视图”按钮清除焦点、恢复推荐缩放并重新居中。
- “适配全图”按钮只调整缩放和平移，使全部节点进入画布，不改变筛选或选择。

焦点效果通过 Cytoscape 元素类实现，例如 `is-focused`、`is-neighbor` 和
`is-dimmed`，不修改拓扑数据。

## 页面结构

在拓扑画布右上角增加两个中文按钮：

- `适配全图`
- `重置视图`

按钮位于画布内部的独立工具条，层级高于 Cytoscape 画布，不遮挡现有筛选栏和
底部图例。视口宽度低于 `760px` 时按钮纵向排列并保持至少 `34px` 高。

## 数据与状态流

1. 页面从现有 API 获取节点和边。
2. 协议、状态、进程及集群筛选产生当前可见元素。
3. 前端根据模式和可见节点数量计算 `layoutLevel`。
4. Cytoscape 使用紧凑多圈配置绘制元素。
5. 初始视图逻辑选择全图适配或最低可读缩放。
6. 用户点击元素时只更新 Cytoscape 样式类和右侧详情。
7. 筛选或模式改变时销毁旧实例、清除焦点并重新计算布局。

空数据、接口错误和无筛选结果仍沿用现有提示，不新增后端错误类型。

## 测试与验证

### 自动化检查

- 页面包含 `适配全图` 和 `重置视图` 按钮。
- 两个按钮具有稳定且唯一的元素 ID。
- 现有页面、API和拓扑测试继续通过。
- Ruff 和完整 Pytest 测试通过。

### 浏览器验证

- 设备模式：少量节点仍保持紧凑单圈，多量节点自动分成多圈。
- 集群模式：受管节点位于内圈，外部地址位于后续圈层。
- 普通节点不小于设计下限，标签和连接数量清晰。
- 点击节点只突出直接相关关系。
- 点击连线只突出该边和两端节点。
- 点击空白处恢复全图亮度。
- `适配全图` 与 `重置视图` 行为符合定义。
- 修改协议、状态、进程或集群筛选后重新布局且无残留高亮。
- 桌面宽屏和窄屏下工具按钮不遮挡图形及图例。

## 完成标准

- 用户能在密集拓扑中清楚辨认节点、端点、标签和连接数量。
- 连线明显短于当前布局，节点数量增加时采用多圈而非持续缩小。
- 聚焦与恢复操作稳定，不影响详情展示和筛选。
- 不新增运行依赖，不修改后端数据结构。
